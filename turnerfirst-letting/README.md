# letting.turnerfirst.com

Site files live in `public_html/`. The repo-root `.cpanel.yml` copies this folder to `/home/turnerfirst/public_html/` when "Deploy HEAD Commit" is run in cPanel > Git Version Control (account `turnerfirst`, repo path `/home/turnerfirst/repositories/agencyeagle`).

Flow: change files here on a branch, merge to `master`, then in cPanel run "Update from Remote" and "Deploy HEAD Commit".
